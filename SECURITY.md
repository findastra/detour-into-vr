# Security Policy

`detour-into-vr` is one of Astra's projects and follows the
[Astra's PetOS security policy](https://github.com/findastra/astras-pet-os/blob/main/SECURITY.md).

**Never report a vulnerability in a public issue.** Report it privately:
[Report a vulnerability](https://github.com/findastra/astras-pet-os/security/advisories/new)
(GitHub private vulnerability reporting). Include what is affected, how to reproduce it and the impact.

How the farm is protected: [PROTECTION-RINGS.md](https://github.com/findastra/astras-pet-os/blob/main/PROTECTION-RINGS.md)
and the [security model](https://github.com/findastra/astras-pet-os/blob/main/docs/security-model-20261018.md).
